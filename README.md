## "电信优化"在 CN2 GIA 上具体优化了哪一段

先把一个常被说错的词拆开。CN2 GIA 是中国电信的承载网产品，走 59.43 开头的 IP 段，联通和移动用不了。所以"三网 CN2 GIA"这个说法，实际含义是三网各有一条优化路径，其中电信那一路是 CN2 GIA，另外两家走的是各自的线路。

测评里拆出来的去程路由是这样的：三网都从北京网口出去，经德国节点转伦敦机房。电信走 59.43 的 CN2 线路，联通走 AS4837，移动走 CMI 骨干网。

回程这块要打个折扣。测评的描述是"三网 CN2 GIA 直连回程"，但正文只逐段列出了去程的三条路由，回程没有给明细。能确认的是电信去程确实走 CN2，回程优化到什么程度，公开资料里没有可复核的路由证据。如果你对回程特别在意，下单前用售前工单问清楚，或者自己拿测试 IP 做一次 traceroute。

这一点对电信用户的实际意义在于：去程走 CN2，意味着你往英国传东西这一段不会先绕去美西再横跨大西洋。回程如果不优化，下载方向仍然要绕。两头都顺，才叫双向。
